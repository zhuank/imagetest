使用帮助

节点操作

  • 添加节点：点击"添加视频节点"按钮创建新的视频处理节点
  • 上传文件：点击或拖拽文件到节点的上传区域
  • 拖拽排序：直接拖拽节点卡片来重新排序
  • 移动节点：使用节点右上角的上下箭头按钮
  • 删除节点：点击节点右上角的删除按钮

节点状态

  • 空闲：节点已创建但未上传文件
  • 就绪：文件已上传，等待处理
  • 处理中：正在处理文件
  • 完成：处理完成
  • 错误：处理过程中出现错误

合并类型

  • 顺序合并：按节点顺序依次合并视频
  • 并排合并：将视频并排显示在同一画面中

使用指南

首尾帧生成

上传首帧和尾帧图片，AI将生成中间过渡视频。适合创建平滑的图片转场效果。

参考图生成

上传1-4张参考图片，AI基于这些图片生成视频内容。支持多样化的创意表达。

视频合并编辑

将多个生成的视频按顺序拼接。支持拖拽排序、批量操作和工作流保存。

快捷键操作

  • Ctrl+Z 撤销操作
  • Ctrl+Y 重做操作
  • Delete 删除选中节点
  • Ctrl+A 全选节点
  • Ctrl+S 保存工作流
  • Space 播放/暂停预览

帮助和引导

🚀 快速开始

欢迎使用视频合并编辑器！

这是一个专业的视频处理工具，支持多种格式的视频文件合并、编辑和处理。

使用步骤：

  • 选择节点类型（视频或音频）
  • 点击"添加节点"按钮或拖拽文件到工作区
  • 调整节点顺序和参数
  • 点击"开始处理"进行合并

⌨️ 键盘快捷键

使用快捷键提高工作效率：

  • Ctrl + Z 撤销操作
  • Ctrl + Y 重做操作
  • Delete 删除选中节点
  • Ctrl + A 全选节点
  • Ctrl + C 复制节点
  • Ctrl + V 粘贴节点
  • Ctrl + S 保存工作流
  • Ctrl + O 加载工作流
  • Escape 取消选择

🎯 核心功能

节点管理

支持拖拽排序、批量操作、分组管理和标签分类。

  • 文件上传：支持拖拽上传，自动格式检测
  • 节点编辑：可调整播放速度、音量、裁剪时间
  • 批量操作：支持全选、批量删除、批量设置
  • 工作流管理：保存和加载工作流配置
  • 实时预览：支持视频缩略图预览

🔧 高级功能

  • 分组管理：右键节点选择"添加到分组"
  • 标签系统：为节点添加自定义标签
  • 模板预设：保存常用的节点配置
  • 异步处理：大文件后台处理，实时进度显示
  • 自动保存：工作进度自动保存到本地

💡 使用技巧

  • 使用右键菜单快速访问节点操作
  • 拖拽节点边缘可调整播放时长
  • 双击节点可快速编辑参数
  • 使用分组功能管理复杂的工作流
  • 定期保存工作流避免数据丢失

🎨 界面定制

  • 点击右上角月亮图标切换暗色主题
  • 界面支持响应式设计，适配各种屏幕
  • 移动端支持触摸操作和手势

❓ 常见问题

  • 文件上传失败：检查文件格式和大小限制
  • 处理速度慢：大文件建议分段处理
  • 预览不显示：确保浏览器支持视频格式
  • 快捷键无效：确保焦点在工作区内
